Le diagnostic UDS

Le protocole de diagnostic des calculateurs : client/serveur, services, sessions, accès sécurisé.

Exemples fictifs, valeurs normalisées. Faites défiler avec les flèches du clavier, le balayage ou les boutons.

À quoi sert le diagnostic ?

AtelierLire et effacer les codes défaut, réinitialiser un calculateur.
ProductionÉcrire des configurations, vérifier un calculateur en fin de ligne.
DéveloppementLire des variables, lancer des routines de test.
Mise à jourReprogrammer la mémoire d’un calculateur.

OBD-II : diagnostic réglementaire (émissions). UDS : ISO 14229. ISO-TP : transport sur CAN (ISO 15765-2).

Client et serveur

Le serveur ne parle jamais de sa propre initiative : il répond à ce que le client demande.

Structure d’un message

MessageFormat
RequêteSID · sous-fonction · données
Réponse positiveSID + 0x40 · sous-fonction · données
Réponse négative7F · SID · NRC
  • Exemples : 0x22 → 0x62, 0x10 → 0x50.
  • Bit 7 de la sous-fonction à 1 : pas de réponse positive (3E 80).

Exemple : lire le numéro de châssis

SensMessage
Requête22 F1 90
Réponse positive62 F1 90 + 17 octets ASCII (« ABCDEFGH123456789 », fictif)
Donnée absente22 F1 91 → 7F 22 31
  • 0xF190 : identifiant normalisé du numéro de châssis (VIN).
  • NRC 0x31 : requête hors plage.
  • La réponse (20 octets) ne tient pas dans une trame CAN : c’est le rôle d’ISO-TP, prochain module.

Les sessions

  • La session détermine les services autorisés.
  • Sans requête pendant le minuteur S3 (≈ 5 s), retour à la session par défaut : TesterPresent la maintient.

L’accès sécurisé (seed/key)

Clé incorrecte : 7F 27 35. Le nombre d’essais est limité. Ce module ne décrit que le principe.

Codes de réponse négative

NRCSignification
0x11 / 0x12Service / sous-fonction non supporté
0x13Longueur ou format incorrect
0x22Conditions non remplies
0x31Hors plage
0x33 / 0x35Accès refusé / clé incorrecte
0x7E / 0x7FNon disponible dans la session en cours
0x78Réponse à venir (pas une erreur)

À retenir

  • Modèle client/serveur : le testeur interroge, le calculateur répond.
  • Réponse positive = SID + 0x40 ; réponse négative = 7F · SID · NRC.
  • Les sessions limitent les services ; TesterPresent les maintient.
  • Accès sécurisé : échange graine/clé.
  • NRC 0x78 : « réponse à venir ». Un DTC tient sur 3 octets plus un octet d’état.
